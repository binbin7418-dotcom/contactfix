One price, the whole toolbox

Other vendors split this into four separate products — a splitter, a merger, an exporter, a duplicate remover — and sell you each one. ContactFix is the whole job in one $29 tool:

  • Duplicate detection — by normalised phone (country code unified, so +86 138…, tel:+86138… and bare 138… count as one number), by email + name, across mixed vCard 2.1 / 3.0 / 4.0 files
  • Lossless merge — fields are unioned, never picked-and-dropped; conflicts are written verbatim into a field-level merge log
  • Damage repair — quoted-printable / base64 mojibake decoded (UTF-8, GBK and more), missing names rebuilt, version chaos normalised to clean vCard 3.0
  • Re-check report — the output is re-parsed and re-scanned: duplicate groups remaining, contact-count conservation, fields lost (target: none)

The merge safety report — the part nobody else shows you

  • Never overwrites. Your export stays byte-identical (we verify this in our own tests with hashes). Output is a new .cleaned.vcf file.
  • Same email ≠ same person. Two contacts sharing an email but carrying different names are not merged — they land in a "Needs your review" list, with the reason printed.
  • Every group explains itself. The merge log shows why each group matched (which phone, which email), which value was kept for every field, and what the losing values were.
